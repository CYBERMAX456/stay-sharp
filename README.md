# 🛡️ Stay Sharp — Cybersecurity Awareness Platform

**Stay Sharp** is a beginner-friendly cybersecurity awareness platform designed to help people recognize social engineering attacks, identify suspicious messages, and build safer online habits.

The platform combines interactive learning, realistic security scenarios, quizzes, and practical safety guidance in one place.

> **Project status:** In development

## ✨ Features

- **Cybersecurity Learning:** Learn the fundamentals of social engineering and common online threats.
- **Phishing Scenarios:** Practice identifying suspicious messages and common warning signs.
- **STOP Method:** Follow a simple approach to pause, verify, and respond safely to suspicious requests.
- **Case Studies:** Explore examples of social engineering risks and their potential consequences.
- **Interactive Security Quiz:** Test your understanding of cybersecurity awareness.
- **Security Checklist:** Review practical steps for improving everyday online safety.
- **Trainer Guide:** Support awareness sessions and structured security education.
- **AI Security Assistant:** Planned or in-development feature for cybersecurity awareness questions and defensive guidance.

## 🎯 Project Goals

- Improve awareness of phishing and social engineering.
- Encourage users to verify suspicious requests before acting.
- Make cybersecurity education accessible to beginners.
- Promote safer account, device, and information-handling practices.

## 🚀 Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/) — use a version supported by your Next.js installation.
- npm — included with Node.js.
- Git — for version control.

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/stay-sharp.git
cd stay-sharp
```

Replace `YOUR-USERNAME` with your GitHub username.

**2. Install dependencies**

```bash
npm install
```

**3. Configure environment variables**

If the AI assistant is enabled, create a `.env.local` file in the project root:

```env
OPENAI_API_KEY=your_api_key_here
```

Replace the placeholder with your own API key. Never commit `.env.local` or expose API keys in client-side code.

If the AI assistant is not configured, follow the project’s current requirements before adding this variable.

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🔐 Security and Responsible Use

Stay Sharp is intended for cybersecurity education and defensive awareness.

- Never share passwords, authentication codes, recovery codes, or API keys.
- Verify suspicious requests through trusted, independent channels.
- Use security testing techniques only on systems you own or have explicit permission to assess.
- Do not treat educational scenarios or AI responses as proof that a message, website, or device is safe.
